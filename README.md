# Portfólio | Stella Gonçalves

Meu portfólio de desenvolvedora Full Stack: quem sou, projetos, habilidades e contato.

## Destaques

- **Céu estrelado** gerado em JavaScript, com estrelas que piscam (e ficam paradas para quem prefere menos movimento)
- **Português e inglês**: um botão troca todos os textos e o currículo baixado
- **Responsivo**, do celular ao desktop
- **Cartão de contato** com botão para copiar o e-mail

## Tecnologias

HTML, CSS e JavaScript puro, em um único `index.html`, sem build.

## Rodando localmente

Basta abrir o `index.html` no navegador.

## Versão antiga

A primeira versão do portfólio está guardada em [Portfolio-antigo](https://github.com/stellag2003/Portfolio-antigo).
